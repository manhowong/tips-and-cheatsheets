# VS Code Tips and Setup

## Essential Extensions

Install extensions from the VS Code Marketplace.

- Minimal Python setup: `Python`, `Pylance`, `Python Debugger`, `Ruff`, `Git`
- For data science: `Jupyter`
- For containerized projects: `Docker`, `Dev Containers`

Suggested extensions:

| Extension name / type | Purpose | 
| ----------------------------------- | ---------------------------------------------------------------------- | 
| **Python**                          | Python support, environments, debugging, testing, IntelliSense |
| **Pylance**                         | Python language server, type analysis, navigation and completion |
| **Python Debugger**                 | Python debugging through `debugpy` |
| **Jupyter**                         | Jupyter notebooks, kernels, interactive execution and data exploration |
| **Ruff**                            | Python linting and formatting |
| **GitLens**                         | Git history, blame, navigation and repository insights |
| **GitHub Pull Requests and Issues** | GitHub pull requests and issues from VS Code |
| **EditorConfig**                    | Consistent indentation, whitespace and editor settings across tools |
| **Docker**                          | Container development and Dockerfile / Compose support |
| **Dev Containers**                  | Reproducible development environments using containers |
| **Remote Development**              | Development over SSH, containers and remote environments |
| **Markdown tools**                  | Markdown editing, preview and navigation |
| **Database extensions**             | SQL editing and database inspection |
| **Data viewers**                    | CSV, JSON, Parquet and other data inspection |

**Note**: For Python, avoid installing multiple extensions that perform the same job. In particular, choose a clear formatter/linter strategy rather than configuring several competing formatters.

## Extensions for Productivity

- **autoDocstring**: Generate docstring template automatically.
- **Better Comments**: Colorcode comments by types (e.g. important note, todo, etc.)
- **Git Graph**: Graph representation of Git Repo.
