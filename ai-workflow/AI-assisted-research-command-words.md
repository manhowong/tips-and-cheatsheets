# AI-Assisted Research: High-level Command Words

## Strategy & Synthesis

| Command | Description | Example |
|---|---|---|
| **Conceptualize** | Outlines a high-level framework, theme, or overarching approach for an idea. | Conceptualise an AI model that acts like a digital twin of a human brain to test drug side effects. |
| **Reconceptualize** | Completely redefines an established phenomenon using a radically new perspective or new data. | Reconceptualise traditional definitions of "brain death" using recent low-level cellular resuscitation data. |
| **Synthesize** | Combines information from multiple conflicting sources into a single, cohesive narrative. | Synthesize 50 conflicting brain-scan studies to find the consensus on how tech addiction impacts focus. |
| **Formulate** | Develops a structured strategy, policy, or methodology based on complex variables. | Formulate an ethical guidelines policy for using AI algorithms to predict genetic diseases in patients. |
| **Extrapolate** | Projects current data, trends, or behaviors into the future to predict potential scenarios. | Extrapolate current lab data on neural implants to predict how human memory processing might change by 2040. |

## Idea Formalization

| Command | Description | Example |
|---|---|---|
| **Map** | Connects informal concepts or data directly to specific variables within an established framework. | Map a user’s description of "feeling a creative spark" to specific dopamine pathways in neurobiological models. |
| **Contextualize** | Places raw findings or ideas within the existing body of literature or historical academic debates. | Contextualize this new AI-driven enzyme discovery within the historical laws of chemical bonding. |
| **Align** | Adjusts a hypothesis so it strictly adheres to the definitions and assumptions of a chosen school of thought. | Align a casual theory about "gut feelings" with established neuroscientific frameworks on the gut-brain axis. |
| **Operationalize** | Turns abstract, real-world concepts into measurable variables defined by a specific framework. | Operationalize the vague concept of "mental fatigue" using measurable metrics like EEG brainwave changes. |
| **Theorize** | Elevates casual observations into formal, testable academic hypotheses or conceptual models. | Theorize why AI models struggle with sarcasm by linking it to human neuro-symbolic language processing. |
| **Formalize** | Rewrites informal, conversational language into the precise, objective tone required for peer review. | Formalize notes saying "the mouse got super excited after the drug" into objective, academic journal phrasing. |
| **Axiomatize** | Reduces a theory or model to a system of core, self-evident truths or mathematical laws. | Axiomatize empirical observations of neural firing rates into a foundational formula for memory retention. |

## Evaluation & Critique

| Command | Description | Example |
|---|---|---|
| **Audit** | Systematically reviews code, text, or a process to identify flaws, risks, or inefficiencies. | Audit a machine learning script to ensure it isn’t accidentally biased against certain demographic groups. |
| **Deconstruct** | Breaks down a complex argument, system, or philosophy to expose its mechanics. | Deconstruct the multi-layered neural network of AlphaFold to show exactly how it predicts protein structures. |
| **Validate** | Checks a statement or dataset against specific logical rules to prove its soundness. | Validate AI-generated brain imaging reports against real, verified clinical diagnoses to check for errors. |
| **Benchmark** | Measures and compares a piece of work or data against industry standards. | Benchmark a new medical AI's accuracy in spotting tumors against the performance of top human radiologists. |
| **Reconcile** | Finds a logical bridge or unified explanation between two seemingly contradictory findings. | Reconcile Study A (sleep improves memory) with Study B (sleep prunes neural paths) into one model. |

## Experimental Design

| Command | Description | Example |
|---|---|---|
| **Isolate** | Separates a specific variable or mechanism from a complex, noisy system to study it independently. | Isolate the specific neural pathway responsible for fear responses while ignoring background anxiety signals. |
| **Confound-Control** | Identifies and logically removes misleading outside variables that distort data interpretation. | Confound-control this AI dataset to ensure patient age isn't skewing its ability to spot early-onset Alzheimer's. |
| **Simulate** | Computationally models a complex, dynamic process to observe potential theoretical outcomes. | Simulate the molecular interaction between a synthetic drug compound and a target cell receptor over 48 hours. |
| **Falsify** | Systematically constructs a test or scenario designed to prove a hypothesis wrong. | Propose a targeted lab experiment to falsify the theory that consciousness requires a prefrontal cortex. |

## Architecture & Optimization

| Command | Description | Example |
|---|---|---|
| **Architect** | Designs the structural blueprint for a system, software application, or complex workflow. | Architect a secure cloud database structure to safely stream live brain-wave data from wearable headsets. |
| **Optimize** | Reworks an existing system or prompt to maximize efficiency while reducing resource use. | Optimize a DNA-sequencing algorithm so it runs in 5 minutes instead of 5 hours using less computing power. |
| **Refactor** | Restructures internal logic or code without changing its external behavior to improve maintainability. | Refactor the messy Python code used in a neuroimaging experiment so other global scientists can easily reuse it. |
